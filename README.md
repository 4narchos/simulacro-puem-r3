# Simulacro PUEM R3 · Cardiología

Examen interactivo: 40 casos, 206 preguntas de opción múltiple.

- Feedback configurable: por respuesta, por caso o al final.
- Puntaje, respuesta correcta y justificación.
- Guarda tus respuestas en el navegador.
- Filtro "solo errores" y reinicio.

https://4narchos.github.io/simulacro-puem-r3/

Para usarlo local: abrir `index.html` en cualquier navegador.
